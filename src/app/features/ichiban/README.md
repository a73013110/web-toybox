# 一番賞模擬器

以有限票池模擬一番賞：每張票只會出現一次，抽出後不放回，所有機率都由當下剩餘數量重新計算。

## 功能

- 自訂 A～G 賞名稱與數量，可將數量設為 0 停用該級別。
- 使用 Web Crypto 與 rejection sampling 產生均勻隨機索引。
- 支援一次抽 1、3、5、10 張，且不會超過剩餘票數。
- 顯示下一張機率，以及本批至少中一次所選獎項的精確機率。
- 抽到整盒最後一張時授予最後賞。
- 票牆、抽票、撕票與批次結果皆支援減少動態效果偏好。

## 演算法

開盒時先按照每個獎項的張數建立完整票組，再以 Fisher–Yates 洗牌。每次抽獎只從 `drawn === false` 的票中選取，批次抽取時會立刻把選中的票移出候選陣列，因此同一批及後續批次都不可能重複。

單抽命中率為 `目標獎項剩餘數 / 全部剩餘票數`。抽 `k` 張至少中一次使用超幾何分布的補事件：

```text
1 - C(全部剩餘 - 目標剩餘, k) / C(全部剩餘, k)
```

實作使用連乘計算「全部沒中」的機率，避免直接計算巨大組合數造成溢位。

## 資料保存

這是個人操作的模擬器，每次進入或重新開盒都會建立獨立票池，因此不需要 Google Sheet。若改為多人共用同一盒，抽獎必須搬到後端，並加入互斥鎖、冪等請求 ID 與不可變的抽獎紀錄；不能只把前端結果寫進 Sheet。

## 驗收重點

- 設定總數為 1、80、200 時皆可完成整盒抽取，且沒有重複票號。
- 批次抽取接近剩餘張數時不會超抽。
- 最後一批包含所有剩餘票時，只有揭票順序中的最後一張取得最後賞。
- 375px 寬度下設定表、票牆、結果層都沒有水平捲軸。
- 鍵盤可以完成設定、抽取、撕票、關閉結果與重新設定。
- 啟用 `prefers-reduced-motion` 後，狀態仍能靠 `animationend` 正常前進。
